# Above website

Static privacy and support website for the Above iPhone sky journal.

## Pages

- `/` — introduction
- `/privacy/` — privacy policy
- `/support/` — support guide and FAQ

## Local preview

Run `python3 -m http.server 5188` from this directory, then open http://localhost:5188/. No build or dependencies are required.

## Hosting

Serve this directory as the website root using a static hosting service. Use a public HTTPS URL for App Store privacy and support links.

The current pages are a draft without operator contact information. Add a real support contact before App Store submission.
